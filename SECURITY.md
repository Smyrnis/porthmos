# Security policy

## Supported versions

Only the newest build on each channel (stable and preview, terminal app and
window app) gets fixes. Porthmos updates itself, so staying current is the fix.

## Reporting a vulnerability

Please do not open a public issue. Use
[private vulnerability reporting](https://github.com/Smyrnis/porthmos/security/advisories/new)
instead, with the version, the platform, and steps to reproduce.

Especially relevant: anything that weakens host-key or TLS certificate
checks, leaks saved passwords or keyring secrets, or gets around the
signature check on updates.

You should hear back within a week.
